Privacy Policy

Last updated: September 30, 2026

Short version: Dealbots does not collect, store, transmit, or sell any personal data. There is no account, no analytics, and no tracking.

What the extension does

Dealbots is a Chrome extension that displays one AI-picked "deal of the day" and a page of other deal picks. It fetches a daily-updated, public JSON feed and displays it. That's the entire functionality.

What data we collect

None. Specifically, Dealbots does not:

  • Require or support any account, login, or sign-up
  • Collect names, emails, location, or any personal information
  • Use analytics, telemetry, or crash reporting
  • Set cookies or use browser storage to track you
  • Read, modify, or have access to the content of the web pages you visit

Network requests the extension makes

The popup fetches a public, non-personalized JSON file from xeonproc.github.io (this same GitHub Pages site) to display today's deal. That request does not include your identity, browsing history, or any other user-specific data — it is the same anonymous request every user's copy of the extension makes.

Affiliate links

"Buy Now" links go to Amazon.com and include an Amazon Associates affiliate tag. If you make a purchase, we may earn a small commission at no extra cost to you. Once you leave the extension and land on Amazon, Amazon's own privacy policy governs any data collected there — Dealbots does not see or receive any information about what you do on Amazon's site.

Permissions

The extension requests host permission for https://xeonproc.github.io/* only, solely to fetch the public deals feed described above and link to the full deals page. No other sites are accessed by the extension.

Changes to this policy

If this policy ever changes, the update will be posted on this same page with a revised "last updated" date.
