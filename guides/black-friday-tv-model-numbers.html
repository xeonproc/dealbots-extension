What a holiday-only or derivative model number is

A model number is the identifier on the carton, on the sticker on the set, on the spec sheet, and in the cart. Holiday-only and derivative describe the same kind of mismatch. A derivative model is a variation on a television that already exists. A holiday-only model is that kind of variation sold for the sale season, and sometimes only then.

The screen size and the series name can match the set people reviewed. The model number does not. One changed character can mark a different region, a different tuner, a different year, or a sale-season variant. The number in the cart is the set you would receive. The name in the headline is a label.

A seasonal version can be built around a different mix of parts. It can be offered only while the sale is running, so it has little price history of its own. The percent off on the page can point at a list price this exact version has rarely sold at, or has not sold at. The set can still be a fair buy. It is a different product from the reviewed one until the spec sheets say otherwise.

The same gap shows up outside televisions: a holiday laptop with less memory, a small appliance with a shorter warranty, or a bundle that puts last year's model in the box. The appliance and the bundle are covered in are Black Friday deals actually real? and Black Friday bundles: real savings or padding? A television is worth its own pass because the differences sit in the picture and the ports, which are easy to miss when the screen size matches.

Why the sale-season set can differ from the review

Read the spec sheet for the model in the cart. A review of a different model number, even one with the same series name and the same size, describes that other set. These are the lines worth comparing.

Panel type

The panel is the screen you look at. Two sets of the same size can use a different panel type, a different way of lighting the picture, or a different approach to dimming bright and dark areas. An LCD panel and an OLED panel are different ways of making that picture. A review of one does not describe the other. If the sheet for the cart model does not name the panel type, that is a missing fact. It is not a match.

Ports

Count the HDMI inputs, then read what each one can do. A seasonal set can drop an input, or keep the count and limit the refresh rate or the audio those ports support. Audio return matters when a soundbar takes its sound from the television. The same pass covers USB, ethernet, and a tuner input if you use an antenna or a cable feed. A missing port is a different set. It is not a discount on the reviewed one.

Refresh rate

The figure that describes the panel is the native refresh rate. A motion-rate number on the product page can be a processing claim, and it is a different figure from the native rate. Sports and games show the difference more than a slow drama does. If one sheet lists a 60 Hz native panel and the other lists a higher native rate, the sets are different products, including when the motion number in the headline looks similar. Read the native rate on both sheets.

Processor

The processor handles picture processing, menus, and the built-in apps. A seasonal model can use a different chip. That can show up as slower menus, fewer picture-processing features, or a smart platform that is a generation behind the reviewed set. You will not see it from the screen size. It is a line on the spec sheet, sometimes under the processor name and sometimes only visible because the full sheet lists fewer features than the reviewed model.

Stand and remote

The feet and the remote are part of what arrives in the box. A different stand can need a wider or narrower surface, and it can change whether a soundbar fits under the screen. A different remote can leave off a backlight, a number pad, or a button that switches inputs. These are smaller differences than the panel. They still belong on the comparison, because they are what you will live with if you use the included stand and the included remote.

Warranty

A seasonal model can carry a shorter warranty, a warranty that starts on a different date, or coverage a holiday seller does not match. Compare the length, what it covers (parts, the panel, labor), and who honors it. A set that costs less because the coverage is shorter is a different offer from the reviewed model at a discount. The screen size can match and the warranty can still be the thing you gave up.

How to compare spec sheets side by side

Open two sheets: the one for the model number in the cart, and the one for the model in the review or the year-round listing. If you cannot find a sheet for the cart model, pause. You are being asked to buy a set you cannot compare.

Write both model numbers down, character by character. If they are not identical, assume the sets differ until the sheets show they do not. Then line up the same rows:

  • Screen size and native resolution
  • Panel type, and how the set handles bright and dark areas
  • Native refresh rate, kept separate from any motion-rate claim
  • HDR formats the sheet actually names
  • Processor, if the sheet names it
  • HDMI count, and what each port supports, including audio return
  • Smart platform, and the version if it is listed
  • Stand type, remote, and anything else the box includes
  • Tuner, if you use an antenna or a cable feed
  • Warranty length, what it covers, and who provides it

Use the maker's sheet when you can find it, and the seller's sheet for the exact model in the cart. Where those two sheets disagree, the disagreement is a question to settle before you pay. Write each difference in a plain sentence: "the cart model has two HDMI ports that support the higher refresh rate, and the reviewed model has four." Leave the percent-off badge out of that list. The badge is arithmetic on a reference price. The sheet is the product.

Which differences matter for most buyers

You do not need every line to match. You need to know which lines change the set you will actually use.

The picture comes first. Panel type, native resolution, and native refresh rate are what you see. If you watch sports or play games, the native refresh rate and whether the HDMI ports support it matter more than a motion-processing number. If you mostly watch shows and movies in a bright room, how bright the panel gets and how it handles reflections matter more than a high refresh rate you will not use. HDR support matters when the sources you watch offer it. A sheet that only says "HDR," without naming the formats, is less specific than one that lists them.

Ports matter for the devices you will plug in: a soundbar, a game console, a disc player, a computer. Count those devices. Fewer HDMI ports are a problem when you will run out, and a smaller issue when a soundbar and one streamer are all you connect. Audio return matters when the soundbar gets its audio from the television. If you use the television speakers, that port feature is not the reason to pass on the set.

The processor and the smart platform matter when you use the set's own apps. If you use an external streamer, a slower built-in system changes less of your day. The stand matters when you are not wall-mounting. The remote matters when you will use it every day and the replacement lacks buttons you rely on. The warranty matters for every buyer, because it is part of the price. Shorter coverage is coverage you did not get.

A small difference can still be a fair buy. A different remote, on a set whose panel, ports, native refresh rate, and warranty match the one you wanted, is a smaller gap than a different panel sold under a similar name. The comparison is how you see which gap the checkout price is asking you to accept.

Check this model's price history

A price chart answers for the model number on the chart. A low for the reviewed set, for a different screen size in the same series, or for last year's set with a similar name, is a low for that other product. Search the exact model number. Match the size and the condition. New, open-box, and refurbished are different offers. How to compare those during the sale is in refurbished vs new on Black Friday.

Read about 30 to 90 days when the chart has them. Thirty days shows a short markup just before the sale. Ninety days is the safer window when that model has already been on sale more than once. A holiday-only model can have a shorter chart, because it may have been offered only for the sale. On a short chart, the first advertised price and the sale price can both sit inside the same brief window. Read the dates. If the "was" price only appears for a few days before the sale, or never appears as a selling price, the percent off is a label. The dollar price is the fact. How a short markup looks on the line is in how to read a price history chart.

When the chart is too short to show a 30 to 90 day low, say so. You can still put today's checkout total next to the year-round model's recent low and decide whether the spec differences are worth the gap. That comparison does not make the year-round model's low into this model's low. If the sets differ in panel, ports, or refresh rate, they do not share a price history.

No chart for this model number? Search that number plus "price" and read dated posts from deal communities. Keep the dollar amounts. Set aside a percent copied from the product page. A page that only shows history for a similar model is answering a different question. The year-round version of this test, including coupon fine print, is in how to tell if a sale is real.

A short checklist before you buy

Answer these from the cart, the two spec sheets, and this model's prices.

  1. 1Is the model number on the cart identical to the model in the review or the year-round listing?
  2. 2Do the sheets match on panel type, native resolution, native refresh rate, and the HDR formats they name?
  3. 3Do the HDMI ports, including what they support, cover the devices I will connect?
  4. 4Are the processor, stand, remote, and warranty the ones I think I am buying?
  5. 5Am I reading the price history for this model number, this size, and this condition?
  6. 6After the differences I wrote down, is this the set I meant, at this checkout price?

When the numbers match, or you have written down every difference and still want this set, and checkout is at or under this model's own recent low, the deal is about this television. If the model number differs and the chart belongs to another set, skip the percent off until you have this model's price.

Questions people ask

What is a holiday-only TV model number?

A holiday-only model, sometimes called a derivative model, is a television sold for the sale season with a model number of its own. It can keep a familiar series name and screen size and still differ in the panel, the ports, the refresh rate, the processor, the stand, the remote, or the warranty. The model number is how you tell it from the set in a review.

Why doesn't a Black Friday TV match the reviewed model?

A review covers one model number. The sale page can use a close name and a different number. Until you line the two spec sheets up, the review describes a different television from the one in the cart.

Which TV spec differences matter for most buyers?

The picture and the ports you will use come first: panel type, native resolution, native refresh rate, and whether the HDMI inputs cover the devices you will connect. The processor and the built-in apps matter when you use the set's own smart platform. The stand matters when you are not wall-mounting. The warranty matters on every set, because shorter coverage is a smaller offer.

How do I compare two TV spec sheets?

Put the two model numbers next to each other. Then compare screen size, panel type, native resolution, native refresh rate, HDR formats, processor, HDMI ports and what each port supports, stand, remote, and warranty. A one-character difference in the model number is a reason to compare the sheets.

Can I use a similar TV's price history?

Use the chart for the exact model number in the cart, at the same size and condition. A low for the reviewed set, or for last year's similar name, belongs to that other set. A holiday model with only a few days of prices has not shown a longer low.

What should I check before buying a Black Friday TV?

Confirm the model number on the cart, the spec differences that matter for how you will use the set, and the recent price of this model. A chart for a different model number does not show whether this set is inexpensive.
